    What it does

    A complete, tested runtime — 59 automated tests, CI on every commit — that degrades gracefully from a full cloud AI stack down to 100% offline and free.

    🗣️

    Hands-free voice AI

    Offline wake word, follow-up conversation without repeating "TARS", streaming replies spoken sentence-by-sentence while the LLM is still thinking.

    🧩

    18 plugin skills

    Drop a decorated Python function in a folder and it becomes an LLM tool: move, look, remember, timers, music, Home Assistant, images…

    🎭

    Adjustable personality

    Humor, honesty and sarcasm dials, plus switchable character cards — TARS, CASE and KIPP included.

    🧬

    Gait learning

    An evolution strategy tunes the walk against verifiable rewards: centimeters on a tape measure, camera displacement, or a domain-randomized MuJoCo sim.

    ⚖️

    Balance first

    IMU fall watchdog relaxes the servos when TARS tips over; a gyro "stability tax" makes smoother gaits win during training.

    🕸️

    Memory & knowledge

    Semantic long-term memory plus a structured knowledge graph, injected into conversations when relevant.

    📱

    Web dashboard

    Streaming chat, browser voice mode from any phone on the LAN (HTTPS built in), movement pad, live learning curve, movie-style onboard display.

    🖥️

    Cloud or fully local

    OpenAI + ElevenLabs for the best experience, or Ollama + Piper + Vosk for a TARS that costs €0/month and never phones home.

    🩺

    Builder-friendly

    tars --doctor self-tests 12 subsystems with fix hints; --benchmark times the voice pipeline; everything runs in simulation on a laptop.

    Build it

    Raspberry Pi 5, a PCA9685 servo driver, three to six servos, ~1.5 kg of PETG and a weekend of printing. From ≈€280 if you already own a 3D printer. The docs are bilingual (English & Italian) and cover everything — including which Bambu Lab printer to buy and how to get the brushed-metal movie finish.

    It learns to walk — with rewards you can verify

    No simulation hand-waving: the reward is real centimeters covered. A (1+1) evolution strategy mutates five gait-timing parameters; you (or the camera, or the IMU) judge the result. A MuJoCo pre-filter — the same gait code, driving physics instead of servos — screens ~18,000 candidates per hour, and a Spearman honesty check tells you how much to trust it on your build.

    $ python -m tars.learn --reward mujoco --iterations 300 --dr 6   # overnight, on a PC
$ python -m tars.learn --correlate                                # how honest is the sim?
$ python -m tars.learn --reward camera --steps 3                  # verify on the real floor
